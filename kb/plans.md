# Plans and Limits

Acme Cloud Storage has three plans: Free, Pro, and Team.

The Free plan includes 5 GB of storage and a maximum file size of 2 GB. Deleted files stay in the trash for 30 days.

The Pro plan costs $8 per month and includes 1 TB of storage. The maximum file size is 50 GB. Deleted files stay in the trash for 90 days.

The Team plan costs $15 per user per month and includes 5 TB of pooled storage shared across the team. The maximum file size is 50 GB. Deleted files stay in the trash for 90 days.
