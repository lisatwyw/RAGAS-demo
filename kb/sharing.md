# Sharing and Versions

Any plan can create a share link for a file or folder. You can set an optional expiry date on any link.

Password-protected links are available on the Pro and Team plans only.

Team administrators can restrict external sharing so files can only be shared with people inside the organization.

Version history keeps previous versions of a file. The Free plan keeps versions for 30 days, Pro for 180 days, and Team for 365 days.
